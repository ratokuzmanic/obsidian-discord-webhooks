This plugin was originally created for my D&D group while I'm DMing a _Curse of Strahd_ campaign, so its scope is intentionally limited. Development will mostly focus on:
- Bug fixes
- Compatibility updates (especially with Obsidian or Discord changes)
- Small improvements I personally need for the campaign   

I don't actively plan to expand the feature set beyond that scope. However, forks and pull requests are welcome. Keep in mind that not all feature additions may be accepted if they fall outside the intended use case.
